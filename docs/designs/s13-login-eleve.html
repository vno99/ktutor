Notes

  • Tous les tokens (couleurs, ombres, radius) proviennent de docs/design-system.md. Aucun hex en dur dans le code de prod.
  • Les hauteurs de touch target sont h-11 (44px) sur les Input et Button — WCAG 2.5.5.
  • Les états d'erreur utilisent aria-invalid="true" + border-error, conformément à Input (cf. design-system § Inputs).
  • L'avatar est composé inline (gap #1 du design) en attendant un composant <Avatar> en s17/s22.
  • Le menu de l'avatar utilise un <details>/<summary> natif (gap #2) — focusable au clavier sans JS.
  • Le 401 et le 404 user sont rendus identiquement (Piège 6 research) : auth.errors.invalidCredentials.
  • Les chaînes sont annotées data-i18n — la clé sera chargée par useTranslations("auth.*").
