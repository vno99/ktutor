    Comment résoudre une équation du second degré avec un discriminant négatif ?

  • ktutor · Maths

    Quand le discriminant Δ = b² − 4ac est négatif, l'équation ax² + bx + c = 0 n'a pas de solution réelle, mais elle admet deux solutions complexes conjuguées : x = (−b ± i√|Δ|) / 2a Par exemple, pour x² + 2x + 5 = 0 : Δ = 4 − 20 = −16 Les solutions sont x = (−2 ± 4i) / 2 = −1 ± 2i. Les nombres complexes s'écrivent sous la forme a + bi, où i² = −1.

    Et comment représenter −1 + 2i dans le plan ?

  • ktutor · Maths

    Dans le plan complexe (axe réel horizontal, axe imaginaire vertical), −1 + 2i se place à l'abscisse −1 et à l'ordonnée 2. Le module (distance à l'origine) vaut √(1 + 4) = √5 ≈ 2.24, et l'argument (angle avec l'axe réel) vaut π − arctan(2) ≈ 2.03 rad.
