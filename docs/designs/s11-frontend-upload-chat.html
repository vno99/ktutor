Donne-moi la formule du discriminant.

Le discriminant d'une équation du second degré ax² + bx + c = 0 est donné par Δ = b² - 4ac. Si Δ > 0, l'équation admet deux solutions réelles ; si Δ = 0, une solution double ; si Δ < 0, aucune solution réelle.

Sources : cours-algebre-3e.pdf (chunk 7), td-equations-2024.pdf (chunk 2)
