Breakpoints (design-system § Layout)

≤ 360 px (smartphone)

Pas de max-w-*, px-4, contenu full-width. Bottom tab bar visible. Header sticky 56 px.

≥ 768 px (tablette)

max-w-3xl (chat) / max-w-2xl (upload) + mx-auto + px-6. Nav desktop visible.

≥ 1280 px (desktop)

Même layout que tablette, plus large. Pas de scroll horizontal sur aucune page.

Gaps (non inventés)

Aucun nouveau composant, aucun nouveau token. Les gaps existants du design-system (Skeleton, Dialog, Tabs, Table, NotificationBell, dark/light toggle, Stop sur stream) restent hors-scope. Le seul besoin est l'outillage de test (axe-core + responsive Playwright) et la vérification réelle du score Lighthouse.
