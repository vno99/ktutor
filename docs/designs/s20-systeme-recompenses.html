Emplacement dans le dashboard /api/dashboard/eleve

Le badge apparaît dans la section supérieure du dashboard (au-dessus des cartes par matière), dans un <Card> réutilisé. Responsive : pleine largeur sur 360px ; colonne de 4/12 (gauche) sur ≥ 768px, avec la carte globale s16 en 8/12 (droite).

Accessibilité & états

  • ARIA : le badge porte aria-label="Niveau ..." ; chaque article a role="listitem" ; la section a aria-label.
  • Contraste : texte sur fond blanc (AA) ; couleur de bordure sur fond blanc (AA pour l'indicateur visuel).
  • Focus visible : le composant production doit avoir :focus-visible (Tailwind) si interactif (clic pour détails).
  • Responsive : testé à 360px (flex-direction column) et 768px+ (row aligné).
